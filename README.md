### 🤖 Reinforcement Learning Trading Environment

A Gymnasium-compatible trading simulator supporting:

- Spot trading
- Portfolio simulation
- PPO training
- Configurable reward functions
- Reproducible research workflows

---

### 🌍 Wildlife Trial Framework — WTF

A configurable environment for studying independently learning agents:

- Multiple species with private RL controllers
- Configurable terrain, rivers, elevation and day–night cycles
- Decision-based paired reproduction and rare birth mutation
- Lineage tracking and species/sex-specific brain selection
- Compact recordings and a separate JavaScript replay viewer
- Agent inspection with sampled brain activity and archived-model explanations

[Repository](https://github.com/sagnik1511/wtf) ·
[Documentation](https://sagnik1511.github.io/wtf/) ·
[PyPI](https://pypi.org/project/wtf-wildlife-trial-framework/)
